Platform overview

stoiXDome is designed as an AWS-specific, serverless-native cloud-security evidence platform for situations where AWS cloud state, identity exposure, operational signals, evidence, and recovery context must be understood as one connected system.

stoiXDome is not positioned as a generic multi-cloud scanner. Its current product direction is AWS-specific: deeper AWS state discovery, AWS-native architecture, controlled evidence generation, serverless-native deployment, and evidence-oriented workflows for AWS environments.

The preferred deployment model is AWS serverless-native: managed APIs, event-driven compute, managed state, queue-based processing, durable object storage, and notification flows. This keeps the product deployment-light and scalable without claiming limitless scale, AWS approval, or serverless as an absolute marketing slogan.

The platform direction is broader than a simple scanner. In public terms, it reviews AWS cloud state, connects selected evidence into reviewable context through controlled review workflows, preserves state-history context, applies scope-based review boundaries, and produces structured reports for technical and external review.

In practical terms, stoiXDome helps teams answer: what changed in an AWS environment, which identities or policies create exposure, what evidence supports that finding, what state history matters, and what response workflow is allowed by policy.
